# Justin3go 风格站点：从 0 到 1 的 SOP

给执行者（人或 AI）用。目标不是抄代码，而是做出**同一气质**的个人站：VitePress 文档博客 + 撕纸拼贴首页。

Agent Skill（可自动触发）：`.agents/skills/justin3go-paper-site/`。新仓库也可把该目录拷到 `~/.cursor/skills/justin3go-paper-site/`。

一句话气质：**干净的技术文档站，首页像一本贴了胶带的手帐。**

---

## 0. 先分清两套界面

| 表面 | 气质 | 技术 |
| --- | --- | --- |
| 全局壳（顶栏、博客、归档、文章、赞助） | VitePress 默认文档站，克制、可读 | 默认主题 + 品牌色 + 少量字体 |
| 首页 `/` | 手帐 / 撕纸 / 明信片 / 信纸 | 自定义 `ProfileHome`，不是文档 layout |

做新站时：**壳用文档站，首页单独做拼贴叙事。** 不要把撕纸效果铺到文章页。

## 1. 风格系统（照这个做，气质才像）

### 1.1 色彩

浅色主题走**纸白 + 深蓝**；深色主题把品牌色换成**金黄**，底仍是 VitePress 炭灰，不要另起一套彩虹。

| Token | 浅色 | 深色 | 用法 |
| --- | --- | --- | --- |
| Brand 1 | `#2949a4` | `#aa9100` | 主按钮、选中态、标题第二行、选中文字底 |
| Brand 2 | `#0749ff` | `#d5b811` | hover |
| Brand 3 | `#7494ec` | `#ecce23` | 弱强调 |
| Brand soft | `rgba(110,156,190,0.14)` | `rgba(186,186,186,0.14)` | 高亮底、当前时间线光晕 |
| 背景 | VitePress 默认白 | VitePress 默认深底 | 不要纯黑纯白硬切 |
| 纸面 | `color-mix(bg 94%, brand 6%)` | 同公式 | 便签、信纸、横线本 |

硬规则：

- 全站只有 **一个品牌色**，浅色蓝、深色黄，成对切换。
- 选中文字：`background: brand-1; color: bg`。
- 首页装饰色全部从 `var(--vp-c-brand-*)` 派生，禁止写死第二套蓝。

### 1.2 字体

| 角色 | 字体 | 用在哪 |
| --- | --- | --- |
| Logo | Niconne（手写衬线，可子集化站点名） | 顶栏标题，约 24px |
| 正文 | 系统中文优先（苹方 / 微软雅黑）+ 西文无衬线 | 文章、首页正文 |
| 装饰宋体 | Source Han Serif CN（可子集） | 博客列表大号镂空日期 |
| 等宽 | Fira Code | kicker、章节号、时间线年份、印章文字 |
| 手写点缀 | Georgia italic | `hello, world.`、信纸签名 |

字号节奏（首页）：kicker / eyebrow `10–11px` + 字距 `0.09–0.12em`；H1 大且略收字距；说明 `14–15px`、行高 `1.9–1.95`。

### 1.3 形状与材质（这是辨识度）

不要圆角卡片、不要大阴影、不要紫渐变。用这些母题：

1. **撕边纸**：`clip-path: polygon(...)` 做不规则边，标题两行各一张纸，第二行微旋 + 品牌底。
2. **胶带**：半透明色条，`-8°` 到 `-10°`。
3. **横线便签**：`repeating-linear-gradient` 29px 一行。
4. **硬投影**：`box-shadow: 2px 6px 0` 实色块，不是模糊阴影。
5. **微旋转**：卡片 `-1.2°`，按钮 `-1.2°` / `+1.2°`，hover 回 `0` 并上移 2px。
6. **章节号**：`01` 等宽数字 + 虚线小方框。
7. **外链箭头**：`↗` 打开，`↘` 页内，`↑` 回顶。

### 1.4 布局

- 内容宽：`min(calc(var(--vp-layout-max-width) - 64px), calc(100% - 64px))`，当前约 1376px。
- 首页桌面：左右对开。人物/纸艺一边，文案一边；章节左右交替（作品左、关于右、运动左、经历右、联系左）。
- 断点 `860px`：人物只留首屏，后面章节纯文案，不要顶部迷你人像条。
- 顶栏不透明，贴主题背景。
- 首页有一层 **sticky 章节导航**（作品 / 关于 / 经历 / 联系），滚到对应区高亮。

### 1.5 动效

- 入场：滚动进入视口才加 class，轻微显现。
- 尊重 `prefers-reduced-motion`：关掉纸片重组和连续镜头，留静态姿态。
- 不劫持滚轮，不强制吸附。
- 纸人连续镜头是加分项，**不是气质必需**。没有素材时，用 CSS 便签 + 胶带也能像。

### 1.6 不要做的

- Inter / Roboto 当品牌脸。
- 三列图标网格、紫色光晕、玻璃拟态。
- 把首页撕纸 clip-path 用到正文 Markdown。
- 文章页放大图预览可以留；首页不要再套一层文档 sidebar。

## 2. 信息架构（最小完整站）

```
/                 拼贴首页（作品、关于、经历、联系）
/blog             分页文章列表（标题 + 日期 + 标签 + 摘要）
/posts/YYYY/MM/..  单篇文章（目录、评论、前后篇）
/archive          按年归档
/support-me       赞助（可砍）
/friends          友链（可砍）
/en/...           英文镜像（可砍）
```

顶栏建议：首页 · 博客 · 归档 ·（赞助）。社交：X / GitHub / RSS。

## 3. 执行顺序（0 → 1）

卡在「没有内容」时不要往下做视觉。内容清单见第 4 节。

### Step A — 骨架（半天）

1. `pnpm create vitepress` 或克隆本仓库后清空 `docs/posts`、`docs/notes`、首页文案。
2. 配 `title`、`description`、`lang`、favicon、顶栏、footer。
3. 品牌 CSS：把第 1.1 节写进 `style.css`（浅色蓝 / 深色黄）。
4. Logo 用手写字体；代码用 Fira Code。

验收：任意 Markdown 页打开，明暗切换时链接和按钮跟着变蓝/变黄。

### Step B — 博客能读（半天）

1. 文章路径：`docs/posts/YYYY/MM/DD-english-slug.md`。
2. Frontmatter：`title`、`date`、`tags`。
3. 摘要必须用两个 `<!-- DESC SEP -->` 包住（列表页靠它抽 excerpt）。
4. 列表页：大标题 + 宋体镂空日期 + outline 标签 + 摘要 + 分页。

验收：3 篇样文能分页、能进正文、标签能看见。

### Step C — 首页拼贴（1–2 天）

按区块做，每块都能单独上线：

1. Hero：头像 + 身份 + kicker + 两行撕边标题 + 两句说明 + 主/次按钮。
2. 右侧纸面（可先静态）：横线本、胶带、印章、一句手写。
3. Sticky 章节导航。
4. 作品：8 张「明信片」卡（16:9 图 + 序号 + 域名 + 一句话）+ 下面纯文字更多项目。
5. 关于：两张生活卡（兴趣 A / 兴趣 B）。
6. 时间线：4–8 条，最新在上，当前项品牌色圆点。
7. 联系：信纸块 + 超大邮箱 + 社交 + 斜体签名。

人物连续镜头、六场景纸片重组：有头像和动作图再加。没有就跳过。

### Step D — 站点完成度（按需）

RSS、sitemap、Twitter Card / OG、图片点击放大、Giscus、Algolia 或本地搜索、中英 i18n、GA。这些不决定「像不像」，只决定「像不像一个上线的博客」。

## 4. 用户必须给什么（决定能不能做好）

原则：**视觉可以猜，身份不能猜。** 缺 Must 就停，用第 5 节问卷去要。

### Must（没有就不要开工首页）

| 项 | 规格 | 为什么 |
| --- | --- | --- |
| 站点名 / 花名 | 短、可当 logo | 顶栏手写字、印章、版权 |
| 一句话身份 | 角色 · 城市 | Hero 头像旁那行 |
| 两行主标题 | 每行 ≤ 8 个汉字或 4 个英文词 | 撕边纸只好看短句 |
| 两句介绍 | 各 15–40 字 | 太长首页会塌 |
| 一句 motto | 例如「赢在执行力，贵在坚持。」 | 页脚与首屏脚注 |
| 头像 | 方图，脸清晰，≥512px | Hero 小圆头；纸人可后补 |
| 联系邮箱 | 真实可点 | 联系区最大元素 |
| 语言 | 只中 / 只英 / 双语 | 结构一开始就要定 |
| 导航范围 | 要不要博客、笔记、赞助 | 决定顶栏，避免返工 |

### Should（有了才像「这个人的站」而不是模板）

| 项 | 规格 | 缺了会怎样 |
| --- | --- | --- |
| 精选项目 4–8 个 | 名、域名、URL、一句话、16:9 截图 | 作品区空洞，气质立刻变简历 |
| 更多项目 | 只需名 + 一句话 + URL | 可选 |
| 经历 4–8 条 | 时间 + 标题 + 40 字内描述 | 时间线没东西可排 |
| 两个生活切片 | 名称 + 2–3 句 + 可选配图/图标方向 | 没有「屏幕之外」 |
| 社交 2–5 个 | 平台 + URL；微信/公众号给二维码图 | 联系区只剩邮箱也行 |
| 署名 | 信纸结尾用的名字 | 默认用站点名 |
| Favicon | ico/png | 浏览器标签页 |

项目截图：桌面首页即可，宽 1200、高 675 左右，不要 App Store 图标。描述写「这是给谁用的」，不要写技术栈清单。

### Nice（有更好，没有用占位或砍掉）

- 纸人参考：全身、固定服装（帽/眼镜/衣服）、透明底；6 个场景（站、写代码、拍照、运动、走、打招呼）。
- 博客：至少 3 篇真文，或明确「先空着，只上首页」。
- 赞助页文案与收款码。
- 友链名单。
- 搜索（Algolia keys 或接受本地搜索）。
- 评论（GitHub repo + Giscus 配置）。
- 统计 ID、域名、OSS 图床。
- 中英对照（同一 slug，两边 frontmatter 对齐）。

### 不要向用户要的

- 色板（已有蓝/黄系统；除非他们强烈讨厌）。
- 组件库选型（本风格 = VitePress + 极少 TDesign：分页、标签）。
- 「参考 10 个竞品」。给 1 个他们喜欢的站即可。
- 完整设计稿。首页结构已经定死，缺的是文案和项目事实。

## 5. 开场问卷（一次问完，复制即用）

把下面发给用户。Must 填不齐就只做文档壳，不做首页拼贴。

```
1. 站点名 / 花名：
2. 一句话身份（角色 · 城市）：
3. 两行主标题：
   行1：
   行2：
4. 短介绍（一句）+ 展开（两句）：
5. Motto：
6. 头像文件（方图）：
7. 邮箱：
8. 语言：只中 / 只英 / 双语
9. 要哪些栏目：博客 / 归档 / 笔记 / 赞助 / 友链
10. 精选项目（每个：名称、域名、链接、一句话、首页截图）：
11. 经历时间线（时间、标题、一句话）：
12. 两个生活切片（名称 + 几句话）：
13. 社交链接 / 二维码：
14. 现在有没有文章？没有的话先空博客还是先写 3 篇？
15. 要不要深色金黄、要不要纸片人物动画？（默认可全要）
```

## 6. 文案口吻（首页）

- 短句，像对人说话，不像 About 页堆形容词。
- 中英都要有「做出来的东西 + 生活的一块」，不要纯工程师简历。
- Eyebrow 用英文小标签：`01 / SELECTED WORK`、`02 / OFF THE SCREEN`。
- 主按钮动词具体：「看看我的作品」，不要「了解更多」。

坏例子：「热爱创新，专注全栈，赋能数字化转型。」  
好例子：「写代码，也收集生活的碎片。」

## 7. 文章格式（直接可发布）

中文：

```markdown
---
title: 中文标题
date: 2026-09-06
tags:
  - Tag1
  - Tag2
---

# 中文标题

> ✨文章摘要（AI生成）
>
<!-- DESC SEP -->
>
> 两到四句摘要。
>
<!-- DESC SEP -->

正文……
```

文件名：`docs/posts/YYYY/MM/DD-english-slug.md`。英文镜像同一文件名放到 `docs/en/posts/...`，翻译 title 和正文，date/tags 保持一致。

## 8. 验收清单

- [ ] 浅色：主按钮深蓝；深色：主按钮金黄。
- [ ] Logo 是手写，不是默认无衬线。
- [ ] 首页 H1 两张微斜撕边纸，不是一条普通标题。
- [ ] 章节导航 sticky，滚动高亮。
- [ ] 项目卡像贴了胶带的明信片，不是圆角阴影卡片。
- [ ] 联系区是信纸，邮箱字号明显大于正文。
- [ ] 860px 以下不横溢、人物不挡标题。
- [ ] 系统「减少动态」时仍可读、可点。
- [ ] 博客列表有日期 + 标签 + 摘要；单篇有目录。
- [ ] 用户 Must 信息全部是真的，没有「Your Name」「lorem」。

## 9. 给 AI 的最短指令

> 按 `design/rebuild-from-zero-sop.md` 做个人站。气质：VitePress 文档壳 + 撕纸手帐首页。品牌：浅色 `#2949a4`，深色 `#aa9100`。先收第 5 节问卷的 Must；Must 齐了再做首页。不要用紫渐变和圆角大阴影。没有纸人素材就用 CSS 便签，不要编造人物。
